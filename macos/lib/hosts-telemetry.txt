# Telemetry / crash reporting / analytics domain blocklist
# Used by harden.sh to null-route known data collection endpoints via /etc/hosts.
#
# WARNING: Some domains here may overlap with update or functional infrastructure.
#          Comments note where this is the case. Review before applying.
#
# Format: one domain per line. Lines starting with # are ignored.
#
# Last reviewed: 2026-03

# ---------------------------------------------------------------------------
# Apple telemetry and diagnostics
# Apple collects crash reports, diagnostic data, and analytics through several
# dedicated endpoints. The entries below target submission-only domains that
# serve no functional purpose for software updates or iCloud services.
#
# NOTE: Do NOT block apple.com, swscan.apple.com, swcdn.apple.com,
#       or updates.apple.com — those are needed for software updates.
# NOTE: Do NOT block albert.apple.com — it is also used by iMessage and
#       FaceTime activation. Blocking it will break iMessage activation.
# NOTE: Do NOT block gateway.icloud.com — breaks iCloud services broadly.
# ---------------------------------------------------------------------------

# Apple crash and diagnostic submission
# radarsubmissions.apple.com — crash report and bug report submission (Feedback Assistant)
radarsubmissions.apple.com
# feedbackassistant.apple.com — Feedback Assistant app submission endpoint
feedbackassistant.apple.com
# diagassets.apple.com — diagnostic asset downloads used by crash reporter
diagassets.apple.com
# iphonesubmissions.apple.com — device submission endpoint
iphonesubmissions.apple.com
# securemetrics.apple.com — Apple security metrics collection
securemetrics.apple.com
# xp.apple.com — Apple analytics and advertising attribution
xp.apple.com

# ---------------------------------------------------------------------------
# Mozilla / Firefox
# Firefox sends telemetry, crash reports, and geolocation queries.
# NOTE: blocking telemetry.mozilla.org does not break browsing or updates.
# NOTE: blocking aus5.mozilla.org WILL prevent Firefox update checks.
# ---------------------------------------------------------------------------
telemetry.mozilla.org
incoming.telemetry.mozilla.org
crash-reports.mozilla.com
crash-stats.mozilla.com
crash-reports-xpsp2.mozilla.com
mozilla-ohttp-relay.fastly.net
location.services.mozilla.com
shavar.services.mozilla.com
safebrowsing.googleapis.com
# Sponsored tiles / Pocket data collection
contile.services.mozilla.com
spocs.getpocket.com
getpocket.cdn.mozilla.net

# ---------------------------------------------------------------------------
# Google / Chromium
# Chromium-based browsers send update pings, safe-browsing lookups, and

# updates and some extension updates — tradeoff is documented here.
# ---------------------------------------------------------------------------
# Crash reporting

# NOTE: the following breaks Safe Browsing — remove from list if you use it

# NOTE: blocking this will prevent Chromium component updates
